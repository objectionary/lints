.printf without formatters

Using the .printf object makes no sense if there are no format specifiers in the template string.

Incorrect:

[] > app
  io.stdout > @
    "Hello Jeff!".printf
      *

Correct:

[] > app
  io.stdout > @
    "Hello %s!".printf
      * "Jeff"
