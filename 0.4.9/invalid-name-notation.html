Invalid name notation

The name of any object must match the regular expression [a-z]+(-[a-z]+)*. Basically, it must follow kebab-case notation, using only Latin letters. No digits, no underscores, no uppercase characters.

Incorrect:

# App.
[] > mainApp
  foo > x1
  bar > y_

Correct:

# App.
[] > main-app
  foo > x
  bar > y
