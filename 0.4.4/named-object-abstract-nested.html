Named object abstract nested

In XMIR, named objects cannot be nested more than one level deep inside an abstract object.

Incorrect:

[] > foo
  xyz
    num > abc
<o base="x" name="φ">
  <o base="y" name="a">
    <o base="z" name="b"/>
  </o>
</o>

Correct:

[] > foo
  num > abc
  xyz $.abc > @
<o name="f">
  <o base="x" name="φ">
    <o base="ξ.a"/>
  </o>
  <o base="y" name="a">
    <o base="ξ.b"/>
  </o>
  <o base="z" name="b"/>
</o>
